# Kit-de-herramientas-educativas-sobre-econom-a-circular-de-Bitcoin-Berl-n
Recursos educativos y de incorporación de Bitcoin de código abierto desarrollados a partir del uso real en economías circulares en Berlín y La Laguna, El Salvador.  Este repositorio documenta flujos de trabajo prácticos utilizados para introducir Bitcoin como herramienta de pago para comerciantes y usuarios
