# **Kit de herramientas educativas sobre economía bitcoin**




Recursos educativos y de incorporación de Bitcoin de código abierto desarrollados a partir del uso real en economías circulares en Berlín y La Laguna, El Salvador.

Este repositorio documenta flujos de trabajo prácticos utilizados para introducir Bitcoin como herramienta de pago para comerciantes y usuarios en contextos cotidianos.

Objetivo
Este kit de herramientas existe para facilitar la incorporación de Bitcoin:

práctico
comprensible
repetible
impulsado por la comunidad
Los materiales aquí presentados se basan en la experiencia directa de campo y están diseñados para ser reutilizados por otras comunidades que construyen economías circulares.

¿Qué hay en este repositorio?

Guía paso a paso para incorporar empresas que acepten pagos con Bitcoin
Centrado en la operación en el mundo real, la seguridad básica y la confianza.

Incorporación de usuarios

Centrado en los pagos cotidianos, la comprensión básica y la seguridad.
Ubicación: onboarding/user-onboarding-guide.md

Filosofía de mantenimiento
Notas sobre cómo se mantiene y actualiza este repositorio a lo largo del tiempo
Ubicación: MANTENIMIENTO.md

Cómo utilizar este kit de herramientas
Los educadores y los equipos de campo pueden utilizar la guía del comerciante durante la incorporación.
Los nuevos usuarios pueden utilizar la guía del usuario para comprender el uso diario de Bitcoin.
Las comunidades pueden adaptar los materiales a su contexto local
Estos recursos son intencionalmente ligeros y prácticos.
